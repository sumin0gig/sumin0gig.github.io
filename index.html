트러블슈팅

안전점검 Navigation

안전점검 과정에서 여러 화면을 순차적으로 이동해야 하고, 언제든 이전 단계로 돌아갈 수 있어야 했습니다.
Modal 내부에 자체 Stack Navigation을 구현해, 특정 단계로 돌아가면 그 이전 기록만 유지되도록 스택을 제어했습니다.

열화상 데이터 시각화

최고·최저 온도 데이터와 Snapshot은 있었지만, 단순 리스트만으로는 시간에 따른 변화를 파악하기 어려웠습니다.
시간별 최고/최저 온도 그래프와 데이터 상세 조회, 해당 시점 Snapshot 확인 기능을 추가해 변화를 한눈에 볼 수 있게 했습니다.

Android / Native Module 대응

React Native 앱에서 Native Module 관련 오류가 발생했습니다.
React Native·npm 패키지·Android SDK·Gradle·Kotlin·Native dependency 버전을 하나씩 점검해 호환되지 않는 의존성과 빌드 환경을 찾아 조정했습니다.

댓글 이미지 대량 로딩 최적화

첨부 이미지가 많은 댓글 목록을 한 번에 불러오면 메모리·렌더링 부담이 커지고, 여러 이미지 요청이 동시에 몰리는 문제가 있었습니다.
댓글을 50개 단위로 페이지네이션하고, 첨부 썸네일·댓글 목록 모두 FlashList로 가상화해 화면에 보이는 항목만 렌더링했습니다. 갱신 시 가장 최근 이미지부터 우선 로드하고 나머지는 800ms간 유예시켜 로딩을 분산했으며, 원본 이미지는 확대 모달을 누를 때만 별도로 지연 로드하도록 분리했습니다.

무한 스크롤 깜빡임 방지

REST API의 x-total(전체 아이템 개수)로 무한 스크롤 종료 여부를 판단했는데, 이 값이 응답 이후에야 state에 반영되다 보니 비교 시점이 어긋나면서 리스트가 순간적으로 깜빡이는 현상이 있었습니다.
스크롤이 하단에 도달해도 페이지를 즉시 올리지 않고 1초의 지연을 둔 뒤 페이지 상태를 갱신하도록 했습니다. state가 안정된 뒤에 비교와 리렌더링이 일어나면서 깜빡임 없이 다음 페이지를 불러올 수 있었고, 응답 개수가 페이지당 요청 개수보다 적어지면 더 이상 요청하지 않는 방식으로 종료 조건을 단순화했습니다.
