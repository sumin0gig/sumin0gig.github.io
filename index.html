소개

대학에서 회계를 전공했고, 지금은 React Native로 모바일 앱을 개발한 지 3년이 되었습니다. 숫자와 규칙을 다루던 회계 공부는 코드의 논리 구조를 이해하는 데도 비슷하게 도움이 되었고, 특히 핀테크나 ERP처럼 정확한 계산과 데이터 흐름이 중요한 도메인에 흥미를 느낍니다.

작은 디테일까지 신경 쓰는 걸 좋아해서, 애니메이션 하나 움직이는 방식이나 알림이 제때 도착하는지 같은 부분까지 직접 확인하고 다듬는 편입니다.

집안일 관리 앱

혼자 사는 사람들을 위한 집안일 관리 React Native 앱. 귀여운 마스코트 캐릭터가 집안일을 함께 챙겨주는 컨셉으로 기획부터 개발까지 진행하고 있습니다.

10개의 단순 도형을 조합한 마스코트 애니메이션 리그 설계 (귀·꼬리는 사용자별로 다른 variant 적용)
variant마다 공통 인터페이스와 pivot 좌표를 공유하는 레지스트리 패턴으로 애니메이션 로직 재사용
